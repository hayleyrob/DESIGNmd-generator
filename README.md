# Personalized DESIGN.md Generator

A browser-based tool for creating structured DESIGN.md files that can be used as a source of truth for designers, developers, and AI coding agents.

Built to help teams document:

- Brand foundations
- Audience context
- UX/UI experiences
- Graphics and imagery
- Design tokens
- Accessibility requirements

All data stays in the browser and can be exported as a clean DESIGN.md file.

---

## Features

✅ Auto-save to local storage

✅ Live markdown preview

✅ Downloadable DESIGN.md export

✅ Design token management

✅ Color token picker

✅ Dynamic component creation

✅ AI-ready documentation structure

---

## Why

As AI coding agents become more capable, design intent often gets lost.

This tool creates a shared design source of truth that can be:

- Dropped into a repository
- Shared with collaborators
- Used by Claude Code
- Used by ChatGPT Agents
- Used by Cursor
- Used by Windsurf

The result is more consistent design implementation and better alignment between humans and AI systems.
